Abstract. The rapidly expanding and energy-intensive production from the Canadian oil sands, one of the largest oil reserves globally, accounts for almost $12 \%$ of Canada’s greenhouse gas emissions according to inventories. Developing approaches for evaluating reported methane $\mathrm { ( C H _ { 4 } ) }$ ) emission is crucial for developing effective mitigation policies, but only one study has characterized $\mathrm { C H } _ { 4 }$ sources in the Athabasca oil sands region (AOSR). We tested the use of $^ { 1 4 } \mathrm { C }$ and $^ { 1 3 } \mathrm { C }$ carbon isotope measurements in ambient $\mathrm { C H } _ { 4 }$ from the AOSR to estimate source contributions from key regional $\mathrm { C H } _ { 4 }$ sources: (1) tailings ponds, (2) surface mines and processing facilities, and (3) wetlands. The isotopic signatures of ambient $\mathrm { C H } _ { 4 }$ indicate that the $\mathrm { C H } _ { 4 }$ enrichments measured at the site were mainly influenced by fossil $\mathrm { C H } _ { 4 }$ emissions from surface mining and processing facilities $( 5 6 \pm 1 8 \% )$ , followed by fossil $\mathrm { C H } _ { 4 }$ emissions from tailings ponds $( 3 4 \pm 1 8 \% )$ and to a lesser extent modern $\mathrm { C H } _ { 4 }$ emissions from wetlands $( 1 0 \pm < 1 \% )$ . Our results confirm the importance of tailings ponds in regional $\mathrm { C H } _ { 4 }$ emissions and show that this method can successfully distinguish wetland $\mathrm { C H } _ { 4 }$ emissions. In the future, the isotopic characterization of $\mathrm { C H } _ { 4 }$ sources and measurements from different seasons and wind directions are needed to provide a better source attribution in the AOSR.

# 1 Introduction

Methane $\mathrm { ( C H _ { 4 } ) }$ is an important greenhouse gas that has 32 times the global warming potential (mass basis) of carbon dioxide $( \mathrm { C O } _ { 2 } )$ on a 100-year timescale and which contributes to the production of ozone, water vapour (in the stratosphere), and $\mathrm { C O } _ { 2 }$ in the atmosphere (Myhre et al., 2013; Etminan et al., 2016). Global $\mathrm { C H } _ { 4 }$ concentration in the atmosphere has almost tripled compared to pre-industrial values (Rubino et al., 2019), largely due to increased anthropogenic activities that include fossil fuel production and use and agriculture (Jackson et al., 2020; Turner et al., 2019). Since most fossil fuel emissions originate from coal, oil, and natural gas exploitation, transportation, and use (Jackson et al., 2020; Saunois et al., 2020), mitigating $\mathrm { C H } _ { 4 }$ emissions from these activities is necessary to fulfil governmental $\mathrm { C H } _ { 4 }$ emissions reduction goals. Furthermore, a fast $\mathrm { C H } _ { 4 }$ mitigation from the oil and gas sector is projected to have a key role in slowing the rate of global warming over the next few decades (Ocko et al., 2021).

Canada contains approximately $10 \%$ of the world’s proven crude oil reserves, with $82 \%$ of these reserves located in the Athabasca oil sands region (AOSR) in Alberta (Alberta Energy Regulator, 2015). Oil sand deposits, composed of a mixture of sand grains, water, bitumen, and clay minerals (Mossop, 1980; Takamura, 1982), are extracted through two methods. Shallow deposits $( < 7 5 \mathrm { m } )$ are recovered through surface mining, and the bitumen is subsequently separated from sands with alkaline warm water, concentrated, upgraded, and refined (Larter and Head, 2014). Residual water, solids, and diluents used to separate the bitumen are then stored in tailings, which depending on their age and composition emit volatile organic compounds (VOCs), reduced sulfur compounds, $\mathrm { C O } _ { 2 }$ , and $\mathrm { C H } _ { 4 }$ (Small et al., 2015). In contrast, the recovery of deeper deposits requires the use of in situ techniques that involve lowering the viscosity of bitumen by injecting steam into the reservoir to extract it (Bergerson et al., 2012). Although only around $20 \%$ of the oil sands deposits are recoverable using surface mining (Alberta Energy Regulator, 2015), surface mining accounts for $45 \% - 6 5 \%$ of the annual crude oil production from oil sands (Holly et al., 2016). Each of these methods has greenhouse gas (GHG) emissions associated with it, and it is estimated that the oil sands account for $12 \%$ of Canada’s total GHG emissions (Government of Canada, 2018). In the AOSR, an aircraft-based study attributed $\mathrm { C H } _ { 4 }$ emissions to three main sources: microbial methanogenesis in tailings ponds $45 \%$ of total $\mathrm { C H } _ { 4 }$ emissions), disturbance of mine faces in open-pit mines $50 \%$ of total $\mathrm { C H } _ { 4 }$ emissions), and facility activities such as venting, cogeneration, and natural gas leakage $5 \%$ of total emissions) (Baray et al., 2018).

Methane emissions from the oil sands are reported annually to Environment and Climate Change Canada (ECCC) through the Greenhouse Gas Reporting Program (GHGRP), based on inventories of facilities that emit more than $1 \times$ $1 0 ^ { 7 } \mathrm { k g } \mathrm { C O } _ { 2 } \mathrm { - e q } . \mathrm { y r } ^ { - 1 }$ (Government of Canada, 2018). The GHGRP and other inventory approaches have varying degrees of accuracy and are vulnerable to uncertainty in the “emission factors” used to calculate the GHG emission rates. Top-down approaches are used to verify inventory-based GHG emission estimates, and aircraft-based top-down estimates in the AOSR have shown that inventories underestimate GHG emissions (Liggio et al., 2019), with an aircraftbased estimate reporting $48 \%$ higher $\mathrm { C H } _ { 4 }$ emissions than in the inventories (Baray et al., 2018). However, these aircraft measurements were limited to a short period of time (summer 2013), and there have not been other studies confirming and updating these findings. Given these limitations, additional measurements of $\mathrm { C H } _ { 4 }$ and source specific tracers are needed to reconcile differences amongst methods, to generate data at different times of the year, and to generate long-term data for monitoring the evolution of AOSR emissions.

We can use $^ { 1 3 } \mathrm { C }$ and $^ { 1 4 } \mathrm { C }$ carbon isotopes to determine the sources of $\mathrm { C H } _ { 4 }$ emissions because different $\mathrm { C H } _ { 4 }$ sources have distinct isotopic compositions (Sherwood et al., 2017; Whalen et al., 1989). $\delta ^ { 1 3 } \bar { \mathrm { C } }$ denotes the ratio of $^ { 1 3 } \mathrm { C }$ relative to $^ { 1 2 } \mathrm { C }$ compared to the Vienna Pee Dee Belemnite (VPDB) standard and reported in parts per thousand. The $\delta ^ { 1 3 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ depends strongly on how $\mathrm { C H } _ { 4 }$ is produced: by microbial activity $( - 6 1 . 7 \pm 6 . 2 \% o )$ , by the thermal breakdown of organic molecules $( - 4 4 . 8 \pm 1 0 . 7 \% o )$ , and by incomplete combustion $( - 2 6 . 2 \pm 1 5 \% o )$ (Sherwood et al., 2017). $\bar { \Delta } ^ { 1 4 } \mathrm { C }$ reports the ratio of $^ { 1 4 } \mathrm { C }$ relative to $^ { 1 2 } \mathrm { C }$ compared to a decay-corrected standard and normalized to a $\delta ^ { 1 3 } \mathbf { C }$ of $- 2 5 \text{‰}$ to account for fractionation (Stuiver and Polach, 1977). Fossil fuels, including $\mathrm { C H } _ { 4 }$ in natural gas, as well as $\mathrm { C H } _ { 4 }$ produced from fossil fuel precursors, lack $^ { 1 4 } \mathrm { C }$ and have a $\Delta ^ { 1 4 } \mathrm { C }$ value of $- 1 0 0 0 \text{‰}$ . In contrast, $\mathrm { C H } _ { 4 }$ produced from other substrates has a $\Delta ^ { 1 4 } \mathrm { C }$ signal close to the contemporary atmospheric $\Delta { } ^ { 1 4 } \mathrm { C O } _ { 2 }$ value (Whalen et al., 1989), which was approximately $-5 \text{‰}$ in 2019 in the Northern Hemisphere, estimated from trends reported by Hammer and Levin (2017). $\mathrm { C H } _ { 4 }$ produced from contemporary substrates does not approximate the atmospheric $\Delta ^ { 1 4 } \mathrm { C H } _ { 4 }$ value (estimated to be $340 \text{‰}$ from the available data), which is determined by the ratio of modern biogenic to fossil methane emissions, as well as the $^ { 1 4 } \mathrm { C }$ enrichment due to global nuclear power plant $^ { 1 4 } \mathrm { C H } _ { 4 }$ emissions (Lassey et al., 2007). The implication is that in the AOSR, $\delta ^ { 1 3 } \mathrm { C }$ can be used to separate thermogenic $\mathrm { C H } _ { 4 }$ from surface mine emissions, and microbial $\mathrm { C H } _ { 4 }$ from tailings ponds, local wetlands, and landfill emissions, while $\Delta ^ { 1 4 } \mathrm { C }$ can further separate the fossil microbial $\mathrm { C H } _ { 4 }$ from tailings ponds from the modern microbial $\mathrm { C H } _ { 4 }$ from landfills and wetlands.

Previous studies have shown that $\delta ^ { 1 3 } \mathrm { C }$ can be successfully used for regional $\mathrm { C H } _ { 4 }$ source attribution in urban, natural, and fossil fuel industrial settings (Eisma et al., 1994; Lowry et al., 2001; Fisher et al., 2011; Townsend-Small et al., 2012; Lopez et al., 2017; Maazallahi et al., 2020), and current instruments allow for relatively cheap and precise $\delta ^ { 1 3 } \mathrm { C }$ determinations in small atmospheric samples using gas-source mass spectrometers or cavity ring-down spectrometers. Conversely, $\Delta ^ { 1 4 } \mathrm { C }$ measurements have been successful in $\mathrm { C O } _ { 2 }$ source attribution (Lopez et al., 2013; Zimnoch et al., 2012; Turnbull et al., 2015b; Miller et al., 2020) but less successful in $\mathrm { C H } _ { 4 }$ source attribution (Eisma et al., 1994; Townsend-Small et al., 2012). Additionally, $\Delta ^ { 1 4 } \mathrm { C }$ measurements are rarely used as analyzing $^ { 1 4 } \mathrm { C }$ requires larger samples than $^ { 1 3 } \mathrm { C }$ analysis, a more demanding extraction of methane from air, and more expensive measurements using accelerator mass spectrometry. Furthermore, $\Delta ^ { 1 4 } \mathrm { C }$ regional source attribution can become complicated in places such as continental Europe where there is a large influence of nuclear power plants with poorly constrained $^ { 1 4 } \mathrm { C H } _ { 4 }$ emissions (Eisma et al., 1994). Improvements in the atmospheric methane collection and processing are currently being developed, which could increase the use of $^ { 1 4 } \mathrm { C H } _ { 4 }$ measurements in the near future (Zazzeri et al., 2021), and at the same time there have been improvements in constraining the influence of nuclear power in $\Delta ^ { 1 4 } \mathrm { C H } _ { 4 }$ measurements (Graven et al., 2019).

In this study, our main goal is to test the use of combined $\Delta ^ { 1 4 } \mathrm { C }$ and $\delta ^ { 1 3 } \mathrm { C }$ measurements in ambient $\mathrm { C H } _ { 4 }$ to estimate contributions from the largest $\mathrm { C H } _ { 4 }$ sources in the AOSR region including wetlands, surface mines, and tailings ponds.

# 2 Methods

# 2.1 Sampling campaign

The sampling campaign took place between 16 and 23 August 2019 at the Environment Canada atmospheric monitoring site Fort McKay South (FMS), adjacent to the Wood Buffalo Environmental Association Air Monitoring Station 13 (AMS13). The monitoring station is located in the AOSR $( 5 7 ^ { \circ } 0 8 ^ { \prime } 5 7 . 5 4 ^ { \prime \prime } \mathrm { N }$ , $1 1 1 ^ { \circ } 3 8 ^ { \prime } 3 2 . 6 6 ^ { \prime \prime } \mathrm { W } )$ , surrounded to the east and west by boreal forest and wetland complexes and to the north and south by oil sands mining and processing facilities (Fig. 1). Air pollution levels at the site depend on the wind direction, and the principal wind directions in Fort McKay are northerly and southerly (Bari and Kindzierski, 2015).

To the north, facilities include the Canadian Natural Resources Limited (CNRL) Horizon Processing Plant and Mine and Muskeg River and Jackpine mines, the Fort Hills Oil Sands Mine, Syncrude Aurora North Mine Site, and the Imperial Oil Kearl Processing Plant and Mine (Government of Canada, 2017). $\mathrm { C H } _ { 4 }$ emissions from CNRL Horizon facilities, Muskeg River and Jackpine mines, and the Syncrude Aurora North Mine have been primarily attributed to openpit mining $( 5 2 0 0 \pm 1 2 0 0 \mathrm { k g h ^ { - 1 } } )$ , but significant $\mathrm { C H } _ { 4 }$ emissions originating from the CNRL Horizon main plant facility $( 1 0 0 0 \pm 3 0 0 \mathrm { k g h ^ { - 1 } } ,$ ) have also been detected (Baray et al., 2018). To the south, the main facilities are Syncrude Canada Mildred Lake and Suncor Energy Inc. oil sands (Government of Canada, 2017). $\mathrm { C H } _ { 4 }$ emissions from these two facilities have been mainly attributed to tailings ponds $( 8 8 0 0 \pm 1 1 0 0 \mathrm { k g } \mathrm { h } ^ { - 1 } )$ followed by open mining $( 4 6 0 0 \pm 6 0 0 \mathrm { k g } \mathrm { h } ^ { - 1 } )$ ) (Baray et al., 2018).

We collected air samples in $7 0 \mathrm { L }$ cylinder tanks by filling the tank for around $1 0 \mathrm { { m i n } }$ to a pressure of $1 3 . 8 \mathrm { M P a }$ using a Bauer PE-100 compressor with a magnesium perchlorate water trap. We aimed to sample $\mathrm { C H } _ { 4 }$ peaks coming from different wind directions. Before the field campaign, the new Bauer PE-100 compressor was tested at the ECCC laboratories and compared to an existing oil-free RIX compressor system, used to fill reference gases (“laboratory standards”) for ECCC. The difference in methane dry air mole fraction in the cylinders when using the Bauer PE-100 and RIX compressor was found to be within $1 0 \mathrm { p p b }$ when consecutively filling tanks using ambient air. During the sampling campaign, we flushed the cylinders two times by filling the tank with air until it reached $1 3 . 8 \mathrm { M P a }$ and subsequently purging the air by opening the tank valve before collecting the air sample.

We performed continuous measurements of methane $\mathrm { ( C H _ { 4 } ) }$ , carbon dioxide $\left( \mathbf { C O } _ { 2 } \right)$ , and carbon monoxide (CO) dry air mole fractions for the whole sampling campaign using a Picarro G2401 gas analyzer, which has a $5 \mathrm { { m i n } }$ average precision of $1 . 5 \mathrm { p p b }$ for CO, $2 0 \mathrm { p p b }$ for $\mathrm { C O } _ { 2 }$ , and $0 . 5 \mathrm { p p b }$ for $\mathrm { C H } _ { 4 }$ . Results were reported as $^ { 1 \mathrm { h } }$ averages of the dry air mole fractions. The intake lines of all the instruments were attached at the rooftop of the air monitoring station, approximately $3 \mathrm { m }$ above ground level (m a.g.l.).

# 2.2 $\mathsf { C H } _ { 4 }$ isotopic analyses

Methane was extracted from the gas samples at the National Institute of Water and Atmospheric Research (NIWA) in Wellington, New Zealand, following the methods described in Lowe et al. (1991), with updates as described in the following. In summary, a mass flow controller set at $1 \mathrm { L m i n } ^ { - 1 }$ was connected to the tanks. Air was drawn from the tanks using a $1 7 0 \mathrm { L m i n } ^ { - 1 }$ rotary pump and pumped through two cryogenic traps to remove $\mathrm { C O } _ { 2 }$ , $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ , ${ \bf N } _ { 2 } { \bf O }$ , and other specific hydrocarbons. Each of these cryogenic traps is made of four $3 5 0 \mathrm { m m }$ long loops passing in and out of liquid nitrogen. The loops are made of $1 2 \mathrm { m m }$ ID Pyrex tubing and are kept at pressures lower than $1 0 \mathrm { k P a }$ . After these first two traps, the sample passed through a third trap containing a Sofnocat reagent (containing platinum and palladium on a tin oxide support) which acts as a catalyst in the conversion of CO to $\mathrm { C O } _ { 2 }$ . This $\mathrm { C O } _ { 2 }$ was subsequently removed using two additional cryogenic traps. Next, $\mathrm { C H } _ { 4 }$ was combusted at $7 5 0 ^ { \circ } \mathrm { C }$ to $\mathrm { C O } _ { 2 }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ using an alumina-supported platinum catalyst. The resulting $\mathrm { C O } _ { 2 }$ was collected and purified in three additional cryogenic traps. Last, $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ was removed using alcohol dry ice traps at $- 8 0 ^ { \circ } \mathrm { C }$ , and $\mathrm { C O } _ { 2 }$ was vacuum distilled into glass vials or break seals for mass spectrometry. Separate extractions were carried out for each $^ { 1 3 } \mathrm { C }$ and $^ { 1 4 } \mathrm { C }$ analysis, processing $2 6 \mathrm { L }$ of air for $^ { 1 3 } \mathrm { C }$ and $2 3 0 { - } 2 9 0 \mathrm { L }$ for $^ { 1 4 } \mathrm { C }$ (depending on $\mathrm { C H } _ { 4 }$ content of the sample).

Analysis of $^ { 1 3 } \mathrm { C }$ was performed on a Thermo MAT-253 isotope ratio mass spectrometer (IRMS) in dual inlet mode. Samples were analyzed against a pure $\mathrm { C O } _ { 2 }$ working reference gas derived from a $^ { 1 3 } \bar { \mathrm { C } }$ -depleted barium carbonate standard (NZCH). The standard deviation for a $\delta ^ { 1 3 } \mathbf { C }$ determination is $0 . 0 2 \text{‰}$ . The results were reported relative to PDB-$\mathrm { C O } _ { 2 }$ . For $^ { 1 4 } \mathrm { C }$ analysis, the methane-derived $\mathrm { C O } _ { 2 }$ was reduced to graphite using $\mathrm { H } _ { 2 }$ and an iron catalyst at $5 5 0 ^ { \circ } \mathrm { C }$ (Turnbull et al., 2015a) and measured for $^ { 1 4 } \mathrm { C }$ content by accelerator mass spectrometry (Zondervan et al., 2015). The results were reported as fraction modern carbon and $\Delta ^ { 1 4 } \mathrm { C }$ age corrected to the date of sample collection following internationally agreed upon conventions (Stuiver and Polach, 1977, Donahue et al., 1990, Reimer et al., 2004). The measurement precision for this dataset is $2 . 2 \text{‰}$ to $2 . 6 \text{‰}$ in $\Delta ^ { 1 4 } \mathrm { C }$ .

# 2.3 Back-trajectory modelling using HYSPLIT-5

We generated hourly $1 2 \mathrm { h }$ backward trajectories for the duration of the sampling campaign using HYSPLIT-5. HYSPLIT is a model for computing atmospheric transport and dispersion of air masses developed by NOAA’s Air Resources Laboratory, and a more complete description of the system can be found in Stein et al. (2015). In this model, a backtrajectory is calculated from a particle that represents a gas being moved by the mean wind field. To calculate the concentration of the trace gas (air concentrations), a number of particles are released from the receptor, and dispersion equations are applied to the upwind trajectory calculation. Then, the mass of the computed particles is added and divided by the volume of their horizontal and vertical distribution. We configured the model to start 3 m a.g.l. from the location of the FMS site and to use meteorological parameters from the NAM $1 2 \mathrm { k m }$ (hybrid sigma pressure US 2010-Present) database.

# 2.4 Estimating source contributions using keeling plots

The Keeling plot approach is based on the conservation of mass in the lower planetary boundary layer (Keeling, 1958, 1961). It assumes that the atmospheric $\mathrm { C H } _ { 4 }$ is the result of a simple mixing between two components, background $\mathrm { C H } _ { 4 }$ and the sum of all $\mathrm { C H } _ { 4 }$ sources, and that the isotope ratio of the two components does not change substantially over time, as in this study. As a result, the intercept of a linear regression between $1 / \mathrm { [ C H _ { 4 } ] }$ and $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ or $\Delta ^ { 1 4 } \mathrm { \bar { C } H _ { 4 } }$ from atmospheric samples is interpreted as the mean isotopic signature of the $\mathrm { C H } _ { 4 }$ sources (Eqs. 1 and 2). Here, we calculated the slope and intercept of the linear regression and their uncertainties after York et al. (2004).

$$
\begin{array} { r l } & { \Delta ^ { 1 4 } \mathrm { C } _ { \mathrm { a i r } } = \frac { \mathrm { C } _ { \mathrm { b a c k g r o u n d } } \left( \Delta ^ { 1 4 } \mathrm { C } _ { \mathrm { b a c k g r o u n d } } - \Delta ^ { 1 4 } \mathrm { C } _ { \mathrm { s o u r c e } } \right) } { \mathrm { C } _ { \mathrm { a i r } } } } \\ & { \qquad + \Delta ^ { 1 4 } \mathrm { C } _ { \mathrm { s o u r c e } } } \\ & { \delta ^ { 1 3 } \mathrm { C } _ { \mathrm { a i r } } = \frac { \mathrm { C } _ { \mathrm { b a c k g r o u n d } } \left( \delta ^ { 1 3 } \mathrm { C } _ { \mathrm { b a c k g r o u n d } } - \delta ^ { 1 3 } \mathrm { C } _ { \mathrm { s o u r c e } } \right) } { \mathrm { C } _ { \mathrm { a i r } } } } \\ & { \qquad + \delta ^ { 1 3 } \mathrm { C } _ { \mathrm { s o u r c e } } } \end{array}
$$

Because the source isotopic signature represents the weighted sum of all the $\mathrm { C H } _ { 4 }$ sources, a mixing model can be used to determine the individual $\mathrm { C H } _ { 4 }$ source contributions from the mean $\mathrm { C H } _ { 4 }$ source isotopic signature if the individual source isotope signatures are known. We used MixSIAR, a Bayesian isotope mixing model framework implemented as an open-source R package (see Stock et al., 2018), to estimate the contribution of potential $\mathrm { C H } _ { 4 }$ sources to the “mixture mean” (mean source signature in air samples). The base of the MixSIAR framework is a mixing model in which the tracer value of the mixture (e.g., $\delta ^ { 1 3 } \mathrm { C } )$ is the sum of the mean tracer value of each source component multiplied by its proportional contribution to the mixture $( p )$ as in Eq. (3). The assumptions for this model are that all the sources are known, tracers are conserved through the mixing process, tracer values do not vary over time, the tracer values differ between sources, and the sum of the proportional contributions $( p )$ is 1 (Stock et al. 2018).

$$
\delta ^ { 1 3 } { \bf C } ^ { \mathrm { m i x t u r e } } = \sum _ { k } \delta ^ { 1 3 } { \bf C } _ { \mathrm { k } } ^ { \mathrm { s o u r c e } } p _ { k }
$$

To account for source uncertainty, MixSIAR incorporates error structures using the summary statistics of the source isotopic values (mean, variance, and sample size), and source parameters are fitted as in Ward et al. (2010). The mixing system can then be solved analytically for multiple tracers simultaneously if the number of sources does not exceed the number of tracers plus one. In this case, we used two tracers, $\delta ^ { 1 3 } \mathrm { C }$ and $\Delta ^ { 1 4 } \mathrm { C }$ , and three sources. The source isotopic values used in the mixing model were derived from the literature and are described in the following section.

# 3 Results and discussion

# 3.1 Isotopic signature of $\mathsf { C H } _ { 4 }$ sources in the AOSR

To estimate the proportion of $\mathrm { C H } _ { 4 }$ emitted from different potential sources, the isotopic signatures of these potential sources must be known. However, specifying the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ from these sources can be especially challenging because $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures can have wide ranges and vary locally (Sherwood et al., 2017), and there are no studies isotopically characterizing $\mathrm { C H } _ { 4 }$ from different sources in the AOSR. Based on the previous aircraft source attribution study (Baray et al., 2018), we identified two main $\mathrm { C H } _ { 4 }$ source categories: $\mathrm { C H } _ { 4 }$ emissions related to the mining and processing of bitumen (e.g., leaking and venting) and tailings pond $\mathrm { C H } _ { 4 }$ emissions. Furthermore, we added wetlands as a third source of regional $\mathrm { C H } _ { 4 }$ emissions as they are estimated to cover approximately $60 \%$ of the Athabasca oil sands region (Rooney et al., 2012), and the wetland $\mathrm { C H } _ { 4 }$ emissions in the province of Alberta have been estimated to be roughly half of the total anthropogenic emissions (Baray et al., 2021).

Thermogenic $\mathrm { C H } _ { 4 }$ associated with Alberta’s Lower Cretaceous oils varies between $- 4 2 \text{‰}$ and $- 4 8 \text{‰}$ (Jha, Gray and Strausz, 1979; Tilley and Muehlenbachs, 2007), but the prevalence of anaerobic biodegradation in shallow subsurface petroleum reservoirs changes the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ composition of heavily degraded oils to between $- 4 5 \text{‰}$ and $- 5 5 \text{‰}$ , in particular by hydrogenotrophic $\mathrm { C H } _ { 4 }$ production (Head et al., 2003; Jones et al., 2008). This biogenically over-printed thermogenic $\mathrm { C H } _ { 4 }$ is present in the mined material of the AOSR, which is potentially released when oil sands are mined, but also during transport, ore preparation, and extraction of bitumen (Johnson et al., 2016). Thus, we used this $\delta ^ { 1 3 } \mathrm { C }$ range to represent $\mathrm { C H } _ { 4 }$ emissions derived from the bitumen mining and processing (Table 1).

Residual water generated from the surface mining process is stored in tailings ponds where aerobic and anaerobic degradation are mainly fuelled by certain naphtha components in the diluents, in specific short-chain $n$ -alkanes $\mathrm { C } _ { 6 }$ to $\mathbf { C } _ { 1 0 } \mathbf { , }$ ), BTEX compounds (i.e., toluene and xylenes), and long-chain $n$ -alkanes $\mathrm { C } _ { 1 4 }$ to $\mathrm { C } _ { 1 8 , }$ ) (Siddique et al., 2006, 2007, 2011, 2012). Radiocarbon measurements of tailings pond components, including total organic carbon (TOC), total lipid extract (TLE), and phospholipid fatty acids (PLFAs), have yielded $\Delta ^ { 1 4 } \mathrm { C }$ signatures of approximately $- 9 9 5 \text{‰}$ (Ahad and Pakdel, 2013). We infer that $\mathrm { C H } _ { 4 }$ is most likely produced from these substrates and therefore has the same $\bar { \Delta } ^ { 1 4 } \mathrm { C }$ signature (Table 1). The chemical composition of the tailings ponds – determined by mineralogy of the oil sands, extraction techniques and additives used, and age of the ponds – influences the microbial communities involved in the substrate degradation (Small et al., 2015), which are likely dominated by syntrophic communities as well as both acetoclastic methanogens, previously associated with short $n$ -alkane degradation, and hydrogenotrophic methanogens, associated with the metabolism of long-chain alkanes and BTEX (Penner and Fogth, 2010; Shahimin et al., 2016; Siddique et al., 2012; Zhou et al., 2012). Measurements of the dissolved $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ from the hypolimnion of Base Mine Lake, a dimictic end pit lake, range between $- 6 0 \text{‰}$ and $- 6 5 \text{‰}$ and to our knowledge are the only available $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ measurements associated with oil sands lakes (Goad, 2017). However, variations in the microbial community composition between ponds result in variations in the rate of $\mathrm { C H } _ { 4 }$ production (Small et al., 2015) and might also result in differences in the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ due to different fractionation in acetoclastic and hydrogenotrophic methanogenesis (Whiticar, 1999; Whiticar et al., 1986). Moreover, the Base Mine Lake $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ value should be regarded as a minimum, because methanotrophic communities are active in the surface of the tailings ponds, most likely shifting the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ towards more positive values during partial oxidation of methane before emission to the atmosphere (Saidi-Mehrabad et al., 2013).

Boreal wetland $\mathrm { C H } _ { 4 }$ emissions are estimated to have a mean $\delta ^ { 1 3 } \mathrm { C }$ value of $- 6 7 . 8 \text{‰}$ , based on atmospheric measurements (Ganesan et al., 2018). In terms of $\Delta ^ { 1 \bar { 4 } } \mathrm { C }$ , wetland $\mathrm { C H } _ { 4 }$ emissions are most likely predominantly modern and close to the atmospheric $\Delta { } ^ { 1 4 } \mathrm { C O } _ { 2 }$ value, even in wetlands associated with permafrost collapse (Cooper et al., 2017; Estop-Aragonés et al., 2020). Because the residence time of carbon released as $\mathrm { C H } _ { 4 }$ in wetlands is likely decadal (Whalen et al., 1989; Chanton et al., 1995), we used a $\Delta ^ { 1 4 } \mathrm { C }$ signature ranging from approximately $40 \text{‰}$ , corresponding to the atmospheric $\Delta ^ { 1 4 } \mathrm { C O } _ { 2 }$ value in the Northern Hemisphere in 2010 (Hammer and Levin, 2017), to approximately $- 1 0 \text{‰}$ , which is the lower limit when using that same dataset to extrapolate for the atmospheric $\Delta ^ { 1 4 } \bar { \mathrm { C O } } _ { 2 }$ value in 2019 (Table 1).

Additional $\mathrm { C H } _ { 4 }$ potential regional sources that were not included in this analysis to avoid having an underdetermined mixing model were forest fires and landfills, both of which would emit $\mathrm { C H } _ { 4 }$ with a modern $\Delta { } ^ { 1 4 } \mathrm { C O } _ { 2 }$ signature. Three major wildfire events occurred in 2019 in Alberta: the Battle complex (Peace River area), Chuckegg Creek wildfire (High Level area), and the McMillan complex (Slave Lake area). The three events started in May and were declared under control on 26 June, 1 July, and 18 August, respectively (MNP LLP 2020), with the third event briefly overlapping with some of the sampling dates (16 to 18 August). However, the event was $2 9 0 \mathrm { k m }$ southwest of the sampling site, while the air in the sampling site originated from the northwest (see Sect. 3.2), and therefore it is unlikely that this was a significant source of $\mathrm { C H } _ { 4 }$ in the air samples. In the case of the landfill, some back trajectories show air masses coming from the general Fort McMurray direction, where the municipal landfill is (Fig. 1). We speculated that between these two sources, wetlands are the most prominent $\mathrm { C H } _ { 4 }$ source because at a provincial level (Alberta), $\mathrm { C H } _ { 4 }$ wetland emissions are estimated to be 2.5 to $3 . 5 \times 1 0 ^ { 9 } \mathrm { k g } \mathrm { a } ^ { - 1 }$ while solid waste disposal accounts for $5 . 2 \times 1 0 ^ { 4 } \mathrm { k g } \mathrm { a } ^ { - 1 }$ (Baray et al., 2021; Environment Climate Change Canada, 2018). If we were to add a landfill component, assuming a $\delta ^ { 1 3 } \mathrm { C }$ value of $- 5 5 \text{‰}$ for landfills (Lopez et al., 2017), the revised estimation would result in a slightly larger contribution of microbial fossil $\mathrm { C H } _ { 4 }$ relative to thermogenic $\mathrm { C H } _ { 4 }$ . For example, if $10 \%$ of the microbial modern emissions were derived from landfills and $90 \%$ from wetlands, our model estimate of the contribution from tailings ponds increases by $2 \%$ (see Sect. 3.3).

# 3.2 Isotopic signature of ambient $\mathsf { C H } _ { 4 }$

Analyses of the $1 2 \mathrm { h }$ back trajectories for the $^ { 7 \mathrm { d } }$ sampling campaign showed that air masses arriving at the FMS station during this time period primarily originated from two general directions (Fig. 2b): from the northwest between 16 and 19 August and from the southwest and southeast between 20 and 23 August. The $\mathrm { C H } _ { 4 }$ mole fraction time series for this time period indicated that most $\mathrm { C H } _ { 4 }$ enrichments were associated with trajectories originating from the west and south, in particular from air masses that transit over the Syncrude Mildred Lake facilities and CNRL Horizon oil sands facilities (Fig. 2).

The $\mathrm { C H } _ { 4 }$ mole fraction $\mathrm { [ C H _ { 4 } ] }$ , $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ , and $\Delta ^ { 1 4 } \mathrm { C H } _ { 4 }$ of the air samples are shown in Table 2. There were significant correlations between $1 / \mathrm { [ C H _ { 4 } ] }$ and $\Delta ^ { 1 4 } \mathrm { C H } _ { 4 }$ $( r ^ { 2 } =$ 0.99; black lines in Fig. 3a), between $1 / \mathrm { [ C H _ { 4 } ] }$ and $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ $( r ^ { 2 } = 0 . 8 4$ ; black lines in Fig. 3b), and between $\Delta ^ { 1 4 } \mathrm { C H } _ { 4 }$ and $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ $( r ^ { 2 } = 0 . 8$ ; black lines in Fig. 3c) in the air samples associated with back-trajectories originating from the south and southwest, corresponding to 20 to 23 August. The intercept of the $\Delta ^ { 1 4 } \mathrm { C }$ Keeling plot for these samples showed a source signature of $- 8 9 8 \pm 9 \text{‰}$ (Fig. 3a), while the intercept of the $\delta ^ { 1 3 } \mathrm { C }$ Keeling plot yielded a source value of $- 5 6 \pm 0 . 8 \%$ (Fig. 3b).

There were also significant correlations between all variables in the samples associated with back-trajectories originating from the north, corresponding to 16 to 19 August (red lines in Fig. 3). However, there were only five data points, and four of them had very similar values, which could artificially strengthen the correlation. When building the $\Delta ^ { 1 4 } \mathrm { C }$ and a $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ Keeling plot with these five samples, the intercepts yielded source values of $\Delta ^ { 1 4 } \mathrm { C } \approx - 1 0 0 0 \%$ and $\delta ^ { 1 3 } \mathbf { C } = - 3 5 . 1 \pm 4 . 5 \%$ , which points to a thermogenic source of $\mathrm { C H } _ { 4 }$ originating in the northern mines.

# 3.3 Source contributions

The approximate contributions from each source category to samples associated with back-trajectories originating from the south were calculated with MixSIAR and are shown in Fig. 4. The microbial and thermogenic fossil enrichment observed in the $\mathrm { C H } _ { 4 }$ air samples $( \sim 9 0 \% )$ indicates that most of the $\mathrm { C H } _ { 4 }$ enrichment observed at the site was influenced by $\mathrm { C H } _ { 4 }$ emissions from the oil sands mines and processing facilities. Specifically, the contribution from thermogenic $\mathrm { C H } _ { 4 }$ was estimated to be $56 \pm 1 8 \%$ while the contribution from fossil microbial $\mathrm { C H } _ { 4 }$ from tailings ponds was estimated to be $34 \pm 1 8 \%$ , with a large uncertainty associated with both estimates (Fig. 4b). The results also indicate an influence of approximately $10 \pm < 1 \%$ from modern microbial sources (Fig. 4b), most likely from wetlands. If most of the modern microbial enrichment is derived from wetlands, it is likely that the contribution from this source is near the annual maximum, as $\mathrm { C H } _ { 4 }$ wetland emissions typically peak in the summer (Baray et al., 2021).

Analyses of the back-trajectories indicated that the air masses from which these sample were collected originated from the south, and therefore the samples are likely predominantly influenced by the Syncrude and Suncor facilities and tailings ponds (Fig. 1). This would explain the substantial enrichment of fossil microbial $\mathrm { C H } _ { 4 }$ in our samples, as measurements of $\mathrm { C H } _ { 4 }$ emissions have shown that the largest $\mathrm { C H } _ { 4 }$ - emitting tailings management areas are Syncrude’s Mildred Lake settling basin and the Base Mine Lake (Small et al., 2015; You et al., 2021). In comparison to the oil sands facilities in the south (Syncrude Mildred Lake and Suncor), the facilities to the north of the air monitoring site have been shown to have much larger $\mathrm { C H } _ { 4 }$ contributions from surface mining and natural gas leaking and venting (Baray et al., 2018), as tailings pond emissions are minimal (below $0 . 1 \mathrm { k g } \mathrm { m } ^ { - 2 } \mathrm { a } ^ { - 1 } ,$ (Small et al., 2015). This was reflected in the few air samples originating from the north that show a $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ of $- 3 5 \text{‰}$ and a $\bar { \Delta ^ { 1 4 } } \mathrm { C H } _ { 4 } ^ { - }$ of $- 1 0 0 0 \text{‰}$ , which is consistent with the isotopic signature of thermogenic $\mathrm { C H } _ { 4 }$ (Fig. 3b).

Compared to the only previous $\mathrm { C H } _ { 4 }$ source attribution study available (Baray et al., 2018), our results implied a lower contribution from tailings ponds and a larger contribution from surface mines and processing facilities. Baray et al. (2018) estimated that $65 \%$ of $\mathrm { C H } _ { 4 }$ emissions from the Syncrude Mildred Lake and Suncor mines and facilities originated from tailings ponds and $34 \%$ from surface mines, but there have not been studies updating these estimates since this study was performed in summer 2013. We suggest that differences between studies can be attributed to changes in bitumen production in the different sites from 2013 and from the large uncertainties in our estimates. The uncertainty in our estimates is mainly due to the uncertainty in the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures of $\mathrm { C H } _ { 4 }$ sources. For example, a change of $5 \text{‰}$ towards more positive values in the tailings pond $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature due to microbial oxidation of $\mathrm { C H } _ { 4 }$ in the epilimnion would increase the calculated contribution from tailings ponds to $5 2 \pm 2 3 \%$ and decrease the thermogenic contribution to $3 8 \pm 2 3 \%$ . This example illustrates the need to reduce the uncertainty in the source isotopic signatures with an extensive $\delta ^ { 1 3 } \dot { \mathrm { C } }$ characterization of $\mathrm { C H } _ { 4 }$ sources in the AOSR, in particular from tailings ponds and surface mines. Furthermore, the use of additional tracers such as methane / ethane $\mathrm { ( C _ { 2 } H _ { 6 } / C H _ { 4 } ) }$ ratios and $\delta ^ { 2 } \mathrm { H }$ in $\mathrm { C H } _ { 4 }$ could help constrain emissions from source categories since biogenic and thermogenic processes yield distinctive $\mathrm { C H } _ { 4 } / \mathrm { C } _ { 2 } \mathrm { H } _ { 6 }$ ratios and $\delta ^ { 2 } \mathrm { H }$ in $\mathrm { C H } _ { 4 }$ (Townsend-Small et al., 2016; Lopez et al., 2017; Douglas et al., 2021).

While an exhaustive $\delta ^ { 1 3 } \mathrm { C }$ characterization of $\mathrm { C H } _ { 4 }$ sources is needed to improve source estimates using carbon isotopes, the clear correlations in our air samples show that this method is useful for estimating $\mathrm { C H } _ { 4 }$ source contributions in regions with multiple $\mathrm { C H } _ { 4 }$ sources like the AOSR. Moreover, the collection of air in cylinders is less costly and easier to do on a regular basis compared to techniques such as aircraft measurements and therefore is well suited for monitoring how source emissions change with time (seasonally and annually). The use of an instrument for continuous $\delta ^ { 1 \bar { 3 } } \mathrm { C H } _ { 4 }$ measurement such as a Picarro G2201-I isotope analyzer could make this process even easier and more evenly distributed through the year.

# 4 Summary and conclusions

We conducted a sampling campaign in the Athabasca oil sands region in summer 2019 with the objective of evaluating the potential of using combined $\Delta ^ { 1 4 } \mathrm { C }$ and $\delta ^ { 1 3 } \mathrm { C }$ measurements in ambient $\mathrm { C H } _ { 4 }$ for source attribution. While tracers such as $\delta ^ { 1 3 } \mathrm { C }$ , δD, and $\mathrm { C _ { 2 } H _ { 6 } / C H _ { 4 } }$ can separate thermogenic from microbially produced $\mathrm { C H } _ { 4 }$ , the use of $\Delta ^ { 1 4 } \mathrm { C }$ indicates if $\mathrm { C H } _ { 4 }$ is produced from a fossil source regardless of the pathway of $\mathrm { C H } _ { 4 }$ formation. We demonstrated the use combined $\Delta ^ { 1 4 } \mathrm { C }$ and $\delta ^ { 1 3 } \mathbf { C }$ measurements for separating emissions from three sources: mines and processing facilities, tailings ponds, and regional wetlands. Our results confirm the importance of tailings ponds in regional $\mathrm { C H } _ { 4 }$ emissions (Baray et al., 2018), which we estimated to be approximately $34 \%$ of all the emissions in the region. Furthermore, the addition of $\Delta ^ { 1 4 } \mathrm { C }$ in the measurements allowed us to separate wetland $\mathrm { C H } _ { 4 }$ emissions, which are a major provincial source of $\mathrm { C H } _ { 4 }$ (Baray et al., 2021) and therefore have the potential to interfere in the accuracy of top-down $\mathrm { C H } _ { 4 }$ estimates. In general, this method proved to be a suitable tool for $\mathrm { C H } _ { 4 }$ source attribution in the AOSR and potentially other oil-producing regions as there are clear correlations between $\delta ^ { 1 \bar { 3 } } \mathrm { C }$ and $\Delta ^ { \bar { 1 } 4 } \mathrm { C }$ isotopic measurements are cheap relative to other approaches such as aircraft measurements, and the instrumentation setup allows for continuous year-round measurements.

Although this study is one of the first to provide a conclusive source attribution using combined $\bar { \Delta ^ { 1 4 } \mathrm { C } }$ and $\delta ^ { 1 3 } \mathbf { C }$ measurements in ambient $\mathrm { C H } _ { 4 }$ , there are still large uncertainties associated with this method, mainly due to the lack of $\delta ^ { 1 3 } \mathbf { C }$ data from key $\mathrm { C H } _ { 4 }$ sources. These uncertainties can be addressed with a characterization of $\delta ^ { 1 3 } \mathbf { C }$ and $\Delta ^ { 1 4 } \mathrm { C }$ in the main $\mathrm { C H } _ { 4 }$ sources and using additional tracers such as methane-to-ethane ratios and $\delta ^ { 2 } \mathrm { H }$ signatures. Moreover, future work should focus on adding measurements at different times of the year and in consecutive years, as seasonal and annual variations in $\mathrm { C H } _ { 4 }$ emissions are currently not well constrained. At a seasonal scale, temperature changes in the winter probably reduce microbial methanogenesis, decreasing tailings pond and wetland emissions, and snow cover in open mining areas could affect $\mathrm { C H } _ { 4 }$ emissions. At an annual scale, changes in mine and processing facilities operations, the development of in situ mining over surface mining, and changes in the age-dependent tailings pond emission profile could also result in $\mathrm { C H } _ { 4 }$ emission variations. Consequently, implementing isotopic measurements for long-term $\mathrm { C H } _ { 4 }$ emission monitoring is essential to have a complete understanding of $\mathrm { C H } _ { 4 }$ emissions in the AOSR and for developing effective mitigation policies.
